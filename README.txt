TechTectonics - Sikkim DisasterConnect
1) Easiest: double-click index.html (works offline on a laptop).
2) With the database backend: install Python 3, run run.bat (Windows) or ./run.sh (Mac/Linux), open http://127.0.0.1:5000
3) To open on ANY device (phone too): upload index.html to a free host such as Netlify Drop (app.netlify.com/drop) and share the link it gives you.
Add events: see backend/README.md and tools/embed_data.py (python3 tools/embed_data.py tools/sikkim_disasters.json index.html).
